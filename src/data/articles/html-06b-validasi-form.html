Setelah struktur form dipahami, kita dapat membantu pengguna memasukkan data dalam format yang benar. Browser memiliki validasi dasar yang dapat dipakai tanpa JavaScript.

1. Pilih Tipe Input yang Sesuai

<label for="email">Email</label>
<input type="email" id="email" name="email">

<label for="sandi">Kata sandi</label>
<input type="password" id="sandi" name="sandi">

<label for="lahir">Tanggal lahir</label>
<input type="date" id="lahir" name="lahir">

<label for="jumlah">Jumlah tiket</label>
<input type="number" id="jumlah" name="jumlah" min="1" max="10">

Tipe yang tepat dapat menampilkan keyboard yang lebih sesuai di ponsel dan memberikan pemeriksaan format dasar.

2. Validasi Bawaan

<label for="username">Username</label>
<input
  type="text"
  id="username"
  name="username"
  required
  minlength="3"
  maxlength="20"
  aria-describedby="bantuan-username"
>
<small id="bantuan-username">Gunakan 3–20 karakter.</small>
  • required mewajibkan nilai.
  • minlength dan maxlength mengatur panjang teks.
  • min dan max mengatur rentang angka atau tanggal.
  • pattern menerima pola ekspresi reguler, tetapi sebaiknya tidak dipakai sebelum Anda memahami polanya.

Pesan bantuan harus tetap terlihat. Jangan hanya menjelaskan aturan melalui placeholder.

3. Validasi Browser Bukan Keamanan Server

Pengguna teknis dapat melewati validasi HTML. Karena itu, server harus memeriksa ulang semua data. Validasi browser bertujuan memperbaiki pengalaman pengguna, bukan menjadi pertahanan keamanan utama.

4. Contoh Form Pendaftaran

<form action="/daftar" method="post">
  <label for="nama">Nama</label>
  <input id="nama" name="nama" required minlength="2">

  <label for="email-daftar">Email</label>
  <input type="email" id="email-daftar" name="email" required>

  <label for="umur">Umur</label>
  <input type="number" id="umur" name="umur" min="13" max="100">

  <button type="submit">Daftar</button>
</form>

Kesalahan Umum

  • Menggunakan type="text" untuk semua jenis data.
  • Membatasi pengguna dengan maxlength tanpa menjelaskan batasnya.
  • Menganggap atribut required cukup untuk keamanan.
  • Memberikan pesan kesalahan hanya melalui warna merah.

Latihan

Tambahkan validasi pada form kontak: nama minimal dua karakter, email wajib dan harus berformat email, serta pesan minimal sepuluh karakter.

Rangkuman

Tipe input dan atribut validasi membantu pengguna, tetapi server tetap wajib memvalidasi data. Selalu berikan label dan petunjuk yang jelas.
