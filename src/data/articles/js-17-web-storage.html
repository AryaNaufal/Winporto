Variabel JavaScript hilang saat halaman dimuat ulang. Web Storage menyimpan data kecil di browser pengguna sehingga tetap ada, misalnya pilihan tema atau isi daftar tugas.

Tujuan Belajar

  • Menyimpan, membaca, dan menghapus data dengan localStorage.
  • Menyimpan array dan object lewat JSON.
  • Mengetahui batas dan risiko penyimpanan di browser.

1. localStorage Dasar

localStorage.setItem("tema", "gelap");

console.log(localStorage.getItem("tema"));    // "gelap"
console.log(localStorage.getItem("tidakada")); // null

localStorage.removeItem("tema");
localStorage.clear();   // hapus SEMUA data situs ini

Data tetap ada walau tab ditutup dan browser dibuka kembali. sessionStorage memiliki cara pakai yang sama, tetapi datanya hilang ketika tab ditutup.

2. Menyimpan Array dan Object

Storage hanya menerima teks, sehingga data lain harus diubah dengan JSON.

const tugas = [{ teks: "Belajar JS", selesai: false }];

localStorage.setItem("tugas", JSON.stringify(tugas));

const tersimpan = JSON.parse(localStorage.getItem("tugas")) ?? [];
console.log(tersimpan);

Tanda ?? [] memberi array kosong ketika belum ada data tersimpan.

3. Fungsi Pembantu yang Aman

Storage dapat gagal (mode privat, diblokir, atau penuh), dan data bisa rusak. Bungkus dengan try...catch.

function muat(kunci, cadangan) {
  try {
    const teks = localStorage.getItem(kunci);
    return teks === null ? cadangan : JSON.parse(teks);
  } catch {
    return cadangan;
  }
}

function simpan(kunci, nilai) {
  try {
    localStorage.setItem(kunci, JSON.stringify(nilai));
  } catch {
    console.warn("Tidak dapat menyimpan data");
  }
}

const tema = muat("tema", "terang");
simpan("tema", "gelap");

4. Contoh: Mode Gelap yang Diingat

const tombol = document.querySelector("#tema");

if (muat("tema", "terang") === "gelap") document.body.classList.add("gelap");

tombol.addEventListener("click", () => {
  const gelap = document.body.classList.toggle("gelap");
  simpan("tema", gelap ? "gelap" : "terang");
});

5. Batas dan Keamanan

  • Kapasitas sekitar 5 MB per situs.
  • Sifatnya sinkron, jadi jangan menyimpan data yang sangat besar.
  • Jangan menyimpan kata sandi, token rahasia, atau data pribadi sensitif: skrip lain di halaman dapat membacanya.
  • Pengguna dapat menghapus atau mengubah isinya kapan saja.

Kesalahan Umum

  • Menyimpan object langsung dan mendapat "[object Object]".
  • Lupa JSON.parse saat membaca sehingga mendapat teks, bukan array.
  • Tidak menangani kasus data belum ada (null).

Latihan

Buat catatan sederhana yang menyimpan isi textarea ke localStorage setiap kali pengguna mengetik, dan memulihkannya saat halaman dibuka lagi.

Rangkuman

localStorage menyimpan teks yang bertahan setelah halaman ditutup. Gunakan JSON untuk data kompleks, bungkus dengan try/catch, dan jangan simpan data rahasia.
