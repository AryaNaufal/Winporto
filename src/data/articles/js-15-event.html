Event adalah kejadian di halaman: klik, ketikan, pengiriman form, atau gulir layar. Dengan event listener, program Anda bereaksi terhadap pengguna.

Tujuan Belajar

  • Memasang event listener dengan addEventListener.
  • Memakai object event.
  • Memahami event delegation.

1. addEventListener

<button id="tombol">Klik saya</button>
<p id="pesan"></p>

const tombol = document.querySelector("#tombol");
const pesan = document.querySelector("#pesan");

tombol.addEventListener("click", () => {
  pesan.textContent = "Tombol diklik!";
});

Argumen pertama adalah jenis event, argumen kedua adalah fungsi (callback) yang dijalankan setiap kali event terjadi.

2. Jenis Event yang Umum

  • click: elemen diklik atau disentuh.
  • input: isi kolom berubah setiap ketikan.
  • change: nilai berubah dan fokus pindah.
  • submit: form dikirim.
  • keydown: tombol keyboard ditekan.
  • mouseover, focus, scroll, DOMContentLoaded.

3. Object Event

const kolom = document.querySelector("#nama");

kolom.addEventListener("input", (event) => {
  console.log(event.target.value);   // isi kolom saat ini
});

document.addEventListener("keydown", (event) => {
  if (event.key === "Escape") console.log("Esc ditekan");
});

event.target adalah elemen yang memicu event. Properti lain: event.key, event.clientX, dan event.type.

4. preventDefault

const form = document.querySelector("form");

form.addEventListener("submit", (event) => {
  event.preventDefault();   // cegah halaman dimuat ulang
  console.log("Form ditangani oleh JavaScript");
});

5. Event Delegation

Untuk daftar yang itemnya sering bertambah, pasang satu listener di induknya, bukan satu per item.

const daftar = document.querySelector(".daftar");

daftar.addEventListener("click", (event) => {
  const item = event.target.closest("li");
  if (!item) return;                 // klik bukan pada li
  item.classList.toggle("selesai");
});

Cara ini tetap berfungsi pada item yang dibuat belakangan, dan lebih hemat memori.

6. Menghapus Listener

function sapa() { console.log("Halo"); }
tombol.addEventListener("click", sapa);
tombol.removeEventListener("click", sapa); // butuh referensi fungsi yang sama

Kesalahan Umum

  • Menulis addEventListener("click", sapa()) sehingga fungsi langsung dipanggil; tulis sapa tanpa kurung.
  • Lupa preventDefault() pada form.
  • Memasang listener di dalam loop pada banyak elemen, padahal delegation lebih sederhana.

Latihan

Buat penghitung dengan tombol tambah dan kurang yang memperbarui angka di halaman. Tambahkan tombol reset, dan cegah angka menjadi negatif.

Rangkuman

addEventListener menghubungkan kejadian dengan fungsi. Object event memberi detail kejadian, preventDefault membatalkan perilaku bawaan, dan delegation menangani banyak elemen dengan satu listener.
