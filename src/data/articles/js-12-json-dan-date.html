JSON adalah format teks standar untuk bertukar data antarprogram, sedangkan Date adalah alat bawaan untuk bekerja dengan tanggal dan waktu. Keduanya sangat sering muncul pada aplikasi nyata.

Tujuan Belajar

  • Mengubah object menjadi JSON dan sebaliknya.
  • Menangani JSON yang tidak valid.
  • Membuat dan memformat tanggal dengan Date.

1. Apa Itu JSON?

JSON (JavaScript Object Notation) mirip object JavaScript, tetapi seluruhnya berupa teks, nama property wajib memakai tanda kutip ganda, dan tidak boleh berisi fungsi.

const produk = { nama: "Buku", harga: 25000, stok: [1, 2, 3] };

const teks = JSON.stringify(produk);
console.log(teks);        // '{"nama":"Buku","harga":25000,"stok":[1,2,3]}'
console.log(typeof teks); // "string"

const kembali = JSON.parse(teks);
console.log(kembali.nama); // "Buku"
  • JSON.stringify: object menjadi teks JSON.
  • JSON.parse: teks JSON menjadi object.

2. Menangani JSON yang Rusak

try {
  const data = JSON.parse("{nama: 'Buku'}"); // bukan JSON valid
} catch (error) {
  console.log("JSON tidak valid:", error.message);
}

Selalu bungkus JSON.parse dengan try...catch bila datanya berasal dari luar program.

3. Tanggal dengan Date

const sekarang = new Date();
console.log(sekarang.getFullYear());  // 2026
console.log(sekarang.getMonth());     // 0-11 (0 = Januari!)
console.log(sekarang.getDate());      // tanggal 1-31
console.log(sekarang.getDay());       // 0-6 (0 = Minggu)

const lahir = new Date(2000, 4, 17);  // 17 Mei 2000 (bulan dimulai dari 0)
const iso = new Date("2026-08-17");   // dari teks format ISO

4. Memformat Tanggal

const t = new Date("2026-08-17T10:30:00");

console.log(t.toLocaleDateString("id-ID", {
  weekday: "long", day: "numeric", month: "long", year: "numeric",
})); // "Senin, 17 Agustus 2026"

console.log(t.toLocaleTimeString("id-ID", { hour: "2-digit", minute: "2-digit" }));
console.log(t.toISOString()); // format standar untuk dikirim ke server

5. Menghitung dengan Tanggal

const mulai = new Date("2026-01-01");
const akhir = new Date("2026-03-01");

const selisihMs = akhir - mulai;                       // dalam milidetik
const hari = selisihMs / (1000 * 60 * 60 * 24);
console.log(hari); // 59

console.log(Date.now()); // milidetik sejak 1 Januari 1970

Kesalahan Umum

  • Lupa bahwa getMonth() dimulai dari 0.
  • Menulis JSON dengan tanda kutip tunggal atau koma di akhir.
  • Menyimpan Date lewat JSON lalu lupa bahwa hasilnya menjadi teks.

Latihan

Ubah array daftar siswa menjadi JSON lalu kembalikan. Kemudian buat fungsi yang menampilkan sisa hari menuju tanggal ulang tahun Anda.

Rangkuman

JSON.stringify dan JSON.parse mengubah data menjadi teks dan sebaliknya (gunakan try/catch saat parsing). Date membuat, menghitung, dan memformat tanggal; ingat bulan dimulai dari 0.
