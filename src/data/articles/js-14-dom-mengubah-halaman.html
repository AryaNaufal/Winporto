Setelah elemen terpilih, Anda dapat mengubah teks, atribut, class, bahkan membuat elemen baru dari nol. Inilah cara aplikasi web memperbarui tampilan tanpa memuat ulang halaman.

Tujuan Belajar

  • Mengubah teks dan atribut elemen.
  • Mengatur class dan gaya dengan aman.
  • Membuat, menambah, dan menghapus elemen.

1. Mengubah Teks

const judul = document.querySelector("#judul");

judul.textContent = "Tugas Hari Ini";        // aman: dianggap teks biasa
// judul.innerHTML = "<em>Tugas</em>";   // menafsirkan HTML (hati-hati!)

Pakai textContent sebagai pilihan utama. innerHTML yang diisi teks dari pengguna dapat membuka celah keamanan XSS, karena skrip jahat bisa ikut dijalankan.

2. Atribut

const gambar = document.querySelector("img");
gambar.setAttribute("alt", "Foto profil");
gambar.src = "foto-baru.jpg";
console.log(gambar.getAttribute("alt"));

const tombol = document.querySelector("button");
tombol.disabled = true;           // nonaktifkan tombol
tombol.dataset.id = "42";         // menulis data-id="42"

3. Class dan Gaya

const kotak = document.querySelector(".kotak");

kotak.classList.add("aktif");
kotak.classList.remove("tersembunyi");
kotak.classList.toggle("gelap");              // tambah jika belum ada, hapus jika ada
console.log(kotak.classList.contains("aktif"));

kotak.style.backgroundColor = "teal";         // gaya langsung (jarang dipakai)

Lebih baik menyiapkan gaya di CSS lalu mengganti class dengan JavaScript, bukan menulis banyak style langsung.

4. Membuat dan Menambah Elemen

const daftar = document.querySelector(".daftar");

const itemBaru = document.createElement("li");
itemBaru.textContent = "Belajar DOM";
itemBaru.classList.add("item");

daftar.append(itemBaru);     // tambah di akhir
daftar.prepend(itemBaru);    // tambah di awal (memindahkan elemen yang sama)

5. Menghapus Elemen

const target = document.querySelector(".item.selesai");
target.remove();

6. Menampilkan Data dari Array

const tugas = ["Belajar HTML", "Belajar CSS", "Belajar JavaScript"];
const daftar2 = document.querySelector(".daftar");

daftar2.innerHTML = "";               // kosongkan dulu
tugas.forEach((teks) => {
  const li = document.createElement("li");
  li.textContent = teks;
  daftar2.append(li);
});

Kesalahan Umum

  • Memakai innerHTML untuk data dari pengguna.
  • Membuat elemen tetapi lupa menambahkannya ke halaman dengan append.
  • Mengakses properti dari hasil null karena selector salah.

Latihan

Dari array ["Apel", "Jeruk", "Mangga"], tampilkan daftar <li> ke dalam <ul>. Tambahkan satu item baru dan beri class baru pada item tersebut.

Rangkuman

Gunakan textContent untuk teks, classList untuk mengatur tampilan, serta createElement, append, dan remove untuk mengubah struktur halaman.
