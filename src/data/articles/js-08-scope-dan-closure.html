Scope menentukan di bagian mana sebuah variabel dapat dipakai. Memahaminya mencegah banyak bug aneh, seperti variabel yang "tiba-tiba tidak ditemukan".

Tujuan Belajar

  • Membedakan global scope, function scope, dan block scope.
  • Memahami hoisting secara sederhana.
  • Mengenal closure lewat contoh penghitung.

1. Global, Function, dan Block Scope

const global = "Terlihat di mana saja";

function tes() {
  const lokal = "Hanya terlihat di dalam fungsi";
  console.log(global, lokal);
}
tes();
// console.log(lokal);  // Error: lokal is not defined

if (true) {
  let dalamBlok = "Hanya di dalam blok if";
  const juga = "Begitu juga const";
}
// console.log(dalamBlok); // Error

let dan const mengikuti block scope: hidup hanya di dalam { } tempat dibuat. Aturan sederhananya, variabel dapat dilihat di tempat ia dibuat dan di dalam blok yang ada di bawahnya.

2. Shadowing

const nama = "Luar";

function cetak() {
  const nama = "Dalam";  // variabel baru yang "menutupi" yang luar
  console.log(nama);     // Dalam
}
cetak();
console.log(nama);       // Luar

3. Hoisting

Deklarasi fungsi biasa dapat dipanggil sebelum ditulis, tetapi variabel let/const tidak dapat dipakai sebelum baris deklarasinya.

halo();                // berfungsi
function halo() { console.log("Halo"); }

// console.log(angka); // Error: Cannot access 'angka' before initialization
let angka = 5;

Praktik terbaik: deklarasikan variabel di atas sebelum dipakai, dan jangan bergantung pada hoisting.

4. Closure

Closure terjadi ketika fungsi "mengingat" variabel dari tempat ia dibuat, meskipun fungsi luar sudah selesai berjalan.

function buatPenghitung() {
  let jumlah = 0;
  return function () {
    jumlah++;
    return jumlah;
  };
}

const hitungA = buatPenghitung();
console.log(hitungA()); // 1
console.log(hitungA()); // 2

const hitungB = buatPenghitung();
console.log(hitungB()); // 1 (penghitung lain, terpisah)

Variabel jumlah tidak dapat diubah dari luar, kecuali lewat fungsi yang dikembalikan. Pola ini sering dipakai untuk menyembunyikan data.

Kesalahan Umum

  • Memakai variabel di luar blok tempat ia dideklarasikan.
  • Membuat banyak variabel global sehingga saling bertabrakan.
  • Memakai var yang cakupannya fungsi, bukan blok.

Latihan

Buat fungsi buatAkun(saldoAwal) yang mengembalikan fungsi setor(jumlah) dan mencetak saldo terbaru. Pastikan saldo tidak dapat diubah langsung dari luar.

Rangkuman

Variabel let/const hidup di dalam blok tempat ia dibuat. Hindari variabel global. Closure memungkinkan fungsi menyimpan data pribadi dari lingkup tempat ia lahir.
