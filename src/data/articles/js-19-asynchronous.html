Sebagian pekerjaan membutuhkan waktu: menunggu data dari internet, timer, atau membaca file. JavaScript tidak berhenti menunggu; ia melanjutkan pekerjaan lain, lalu kembali saat hasilnya siap. Inilah pemrograman asynchronous.

Tujuan Belajar

  • Memahami perbedaan kode sinkron dan asinkron.
  • Memakai setTimeout, Promise, dan async/await.
  • Menjalankan beberapa tugas bersamaan dengan Promise.all.

1. Sinkron vs Asinkron

console.log("1. Mulai");

setTimeout(() => {
  console.log("2. Dari timer (setelah 1 detik)");
}, 1000);

console.log("3. Selesai");
// Urutan hasil: 1, 3, 2

Walaupun timer ditulis di tengah, hasilnya muncul terakhir. JavaScript menjalankan satu hal pada satu waktu, tetapi tugas yang menunggu dititipkan ke browser dan dipanggil kembali setelah selesai.

2. setTimeout dan setInterval

const id = setInterval(() => {
  console.log("Setiap 1 detik");
}, 1000);

setTimeout(() => clearInterval(id), 3500);  // hentikan setelah 3,5 detik

3. Promise

Promise adalah "janji" hasil yang akan datang. Statusnya: pending (menunggu), fulfilled (berhasil), atau rejected (gagal).

function tunggu(ms) {
  return new Promise((resolve) => setTimeout(resolve, ms));
}

function ambilNama() {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      const berhasil = true;
      if (berhasil) resolve("Sinta");
      else reject(new Error("Gagal mengambil data"));
    }, 500);
  });
}

ambilNama()
  .then((nama) => console.log("Halo,", nama))
  .catch((error) => console.log(error.message))
  .finally(() => console.log("Selesai"));

4. async dan await

Cara menulis Promise yang terbaca seperti kode biasa dari atas ke bawah.

async function jalankan() {
  try {
    console.log("Mengambil...");
    const nama = await ambilNama();   // tunggu sampai selesai
    console.log("Halo,", nama);
    await tunggu(1000);
    console.log("Satu detik kemudian");
  } catch (error) {
    console.log("Gagal:", error.message);
  }
}

jalankan();

await hanya boleh dipakai di dalam fungsi async (atau di level atas module). Fungsi async selalu mengembalikan Promise.

5. Promise.all

async function ambilSemua() {
  const [a, b] = await Promise.all([ambilNama(), ambilNama()]);
  console.log(a, b);   // keduanya berjalan bersamaan
}
ambilSemua();

Bila tugas tidak saling bergantung, Promise.all jauh lebih cepat daripada await satu per satu.

Kesalahan Umum

  • Lupa await sehingga yang didapat adalah Promise, bukan hasilnya.
  • Tidak menangani error (catch atau try/catch).
  • Memakai await berurutan untuk tugas yang sebenarnya dapat paralel.

Latihan

Buat fungsi hitungMundur(n) yang mencetak angka dari n sampai 1 dengan jeda 1 detik antar angka memakai async/await dan fungsi tunggu.

Rangkuman

Tugas yang menunggu tidak memblokir program. Promise mewakili hasil di masa depan, async/await membuatnya mudah dibaca, dan Promise.all menjalankan beberapa tugas sekaligus.
