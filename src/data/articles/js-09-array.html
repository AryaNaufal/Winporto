Array adalah daftar nilai berurutan dalam satu variabel. Daftar belanja, daftar nilai ujian, atau daftar produk semuanya cocok disimpan dalam array.

Tujuan Belajar

  • Membuat array dan mengakses isinya lewat indeks.
  • Menambah dan menghapus item.
  • Menyalin array dan membongkar isinya dengan destructuring.

1. Membuat dan Mengakses Array

const buah = ["apel", "jeruk", "mangga"];

console.log(buah[0]);          // "apel" (indeks mulai dari 0)
console.log(buah[2]);          // "mangga"
console.log(buah.length);      // 3
console.log(buah[buah.length - 1]); // item terakhir
console.log(buah.at(-1));      // juga item terakhir

buah[1] = "pisang";            // mengganti isi
console.log(buah);

Array yang dideklarasikan dengan const tetap boleh diubah isinya; yang tidak boleh hanyalah mengganti variabelnya dengan array lain.

2. Menambah dan Menghapus

const antrean = ["Ani", "Budi"];

antrean.push("Citra");     // tambah di akhir  -> Ani, Budi, Citra
antrean.unshift("Dewi");   // tambah di awal   -> Dewi, Ani, Budi, Citra
const keluar = antrean.shift(); // ambil dari awal -> "Dewi"
const terakhir = antrean.pop(); // ambil dari akhir -> "Citra"

console.log(antrean, keluar, terakhir);

3. Mencari dan Memotong

const angka = [10, 20, 30, 40, 50];

console.log(angka.includes(30));   // true
console.log(angka.indexOf(40));    // 3 (-1 jika tidak ada)
console.log(angka.slice(1, 3));    // [20, 30] (tidak mengubah asli)
console.log(angka.join(" - "));    // "10 - 20 - 30 - 40 - 50"

angka.splice(1, 2);                // hapus 2 item mulai indeks 1 (MENGUBAH asli)
console.log(angka);                // [10, 40, 50]

4. Menyalin dan Menggabung dengan Spread

const a = [1, 2];
const b = [3, 4];

const gabung = [...a, ...b];   // [1, 2, 3, 4]
const salinan = [...a];        // salinan baru

salinan.push(99);
console.log(a);                // [1, 2] (tidak ikut berubah)

const salinan = a tidak membuat salinan; kedua variabel menunjuk array yang sama.

5. Destructuring Array

const [pertama, kedua, ...sisa] = ["a", "b", "c", "d"];
console.log(pertama, kedua, sisa); // a b ["c", "d"]

Kesalahan Umum

  • Mengira indeks mulai dari 1.
  • Menyalin dengan = lalu heran saat array asli ikut berubah.
  • Mengakses indeks di luar jangkauan sehingga mendapat undefined.

Latihan

Buat array berisi lima nama. Tambahkan satu nama di akhir, hapus nama pertama, lalu cetak tiap nama dengan for...of. Kemudian buat salinannya dan urutkan kebalikan secara manual.

Rangkuman

Array menyimpan daftar berindeks. push/pop bekerja di akhir, unshift/shift di awal, slice tidak mengubah array, splice mengubahnya, dan spread membuat salinan.
