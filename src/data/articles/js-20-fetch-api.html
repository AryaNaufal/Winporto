Hampir semua aplikasi web mengambil data dari server: daftar produk, cuaca, atau profil pengguna. fetch() adalah fungsi bawaan browser untuk melakukan permintaan HTTP.

Tujuan Belajar

  • Mengambil data JSON dengan fetch.
  • Menangani loading dan error dengan benar.
  • Mengirim data dengan metode POST.

1. Permintaan GET Pertama

async function ambilTugas() {
  const response = await fetch("https://jsonplaceholder.typicode.com/todos/1");
  const data = await response.json();
  console.log(data);
}

ambilTugas();

fetch menghasilkan Promise berisi response. Memanggil response.json() membaca isi sebagai JSON, dan itu juga Promise, sehingga perlu await lagi.

2. Memeriksa response.ok

fetch hanya gagal bila jaringan putus. Jawaban seperti 404 atau 500 tetap dianggap berhasil, sehingga Anda harus memeriksanya sendiri.

async function ambilData(url) {
  const response = await fetch(url);
  if (!response.ok) {
    throw new Error(`Permintaan gagal (status ${response.status})`);
  }
  return response.json();
}

3. Menampilkan Data ke Halaman

<p id="status"></p>
<ul id="daftar"></ul>

const status = document.querySelector("#status");
const daftar = document.querySelector("#daftar");

async function tampilkan() {
  status.textContent = "Memuat…";
  try {
    const tugas = await ambilData("https://jsonplaceholder.typicode.com/todos?_limit=5");

    daftar.innerHTML = "";
    tugas.forEach((t) => {
      const li = document.createElement("li");
      li.textContent = (t.completed ? "✓ " : "") + t.title;
      daftar.append(li);
    });
    status.textContent = "";
  } catch (error) {
    status.textContent = "Gagal memuat data. Coba lagi nanti.";
    console.error(error);
  }
}

tampilkan();

Selalu sediakan tiga keadaan: memuat, berhasil, dan gagal, agar pengguna tidak melihat layar kosong.

4. Mengirim Data dengan POST

async function kirimTugas(judul) {
  const response = await fetch("https://jsonplaceholder.typicode.com/todos", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ title: judul, completed: false }),
  });
  if (!response.ok) throw new Error("Gagal menyimpan");
  return response.json();
}

kirimTugas("Belajar fetch").then((hasil) => console.log(hasil));

5. Catatan Penting

  • Server harus mengizinkan permintaan dari situs Anda (aturan CORS). Error CORS muncul di Console.
  • Jangan menaruh kunci API rahasia di JavaScript browser; siapa pun dapat melihatnya.
  • Gunakan textContent, bukan innerHTML, saat menampilkan data dari luar.

Kesalahan Umum

  • Lupa await pada response.json().
  • Tidak memeriksa response.ok.
  • Tidak memberi tampilan loading dan error.

Latihan

Ambil daftar pengguna dari https://jsonplaceholder.typicode.com/users, tampilkan nama dan email dalam daftar, serta tampilkan pesan bila pengambilan gagal.

Rangkuman

Gunakan fetch dengan async/await, periksa response.ok, ubah isi dengan response.json(), dan tangani keadaan memuat serta gagal. Kirim data dengan method, headers, dan body.
