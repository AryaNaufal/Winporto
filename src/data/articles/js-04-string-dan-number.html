Teks (string) dan angka (number) adalah data yang paling sering Anda olah. JavaScript menyediakan banyak alat bawaan untuk keduanya.

Tujuan Belajar

  • Menggabungkan teks dengan template literal.
  • Memakai method string yang umum.
  • Membulatkan dan mengonversi angka, serta memakai Math.

1. Template Literal

Gunakan tanda backtick ` dan ${} untuk menyisipkan nilai ke dalam teks.

const nama = "Sinta";
const poin = 80;

console.log("Halo, " + nama + "! Poin: " + poin);   // cara lama
console.log(`Halo, ${nama}! Poin: ${poin + 5}`);     // cara modern

2. Method String

const kalimat = "  Belajar JavaScript  ";

console.log(kalimat.length);                 // 22
console.log(kalimat.trim());                 // "Belajar JavaScript"
console.log(kalimat.toUpperCase());          // "  BELAJAR JAVASCRIPT  "
console.log(kalimat.includes("Java"));       // true
console.log(kalimat.trim().slice(0, 7));     // "Belajar"
console.log(kalimat.trim().split(" "));      // ["Belajar", "JavaScript"]
console.log(kalimat.replace("Java", "Type")); // "  Belajar TypeScript  "

String bersifat immutable: method di atas tidak mengubah string asli, melainkan menghasilkan string baru.

3. Bekerja dengan Angka

console.log(parseInt("42px"));     // 42
console.log(parseFloat("3.14abc")); // 3.14
console.log((3.14159).toFixed(2));  // "3.14" (hasilnya teks)
console.log(Number.isNaN(Number("abc"))); // true

4. Objek Math

console.log(Math.round(4.6));  // 5
console.log(Math.floor(4.9));  // 4
console.log(Math.ceil(4.1));   // 5
console.log(Math.max(3, 9, 5)); // 9
console.log(Math.min(3, 9, 5)); // 3

// Angka acak 1 sampai 6 (seperti dadu)
const dadu = Math.floor(Math.random() * 6) + 1;
console.log(dadu);

Kesalahan Umum

  • Memakai tanda kutip biasa dan berharap ${} bekerja; harus backtick.
  • Menganggap toUpperCase() mengubah variabel aslinya.
  • Lupa bahwa 0.1 + 0.2 tidak persis 0.3 pada semua bahasa pemrograman yang memakai floating point.

Rangkuman

Template literal memudahkan menyusun teks. Method string menghasilkan nilai baru, bukan mengubah yang lama. Math membantu membulatkan, mencari nilai terbesar, dan membuat angka acak.
