Tabel digunakan untuk data yang mempunyai hubungan baris dan kolom. Tabel bukan alat untuk menyusun layout halaman.

1. Struktur Dasar

<table>
  <caption>Jadwal Kelas Web Dasar</caption>
  <thead>
    <tr>
      <th scope="col">Hari</th>
      <th scope="col">Materi</th>
      <th scope="col">Durasi</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Senin</td>
      <td>HTML</td>
      <td>90 menit</td>
    </tr>
    <tr>
      <td>Rabu</td>
      <td>CSS</td>
      <td>90 menit</td>
    </tr>
  </tbody>
</table>
  • caption menjelaskan tujuan tabel.
  • thead membungkus kelompok kepala tabel.
  • tbody membungkus data utama.
  • tr adalah satu baris.
  • th adalah sel judul dan td adalah sel data.
  • scope="col" menjelaskan bahwa header berlaku untuk kolom.

2. Header Baris

<table>
  <caption>Nilai Siswa</caption>
  <tbody>
    <tr>
      <th scope="row">Ayu</th>
      <td>90</td>
    </tr>
    <tr>
      <th scope="row">Bima</th>
      <td>85</td>
    </tr>
  </tbody>
</table>

scope membantu pembaca layar menghubungkan nilai dengan header yang tepat.

3. Menggabungkan Sel

colspan menggabungkan kolom dan rowspan menggabungkan baris. Gunakan seperlunya karena tabel yang terlalu kompleks sulit dibaca di layar kecil.

<tr>
  <th colspan="2">Data Kontak</th>
</tr>

Kesalahan Umum

  • Menggunakan tabel untuk layout dua kolom.
  • Mengosongkan caption pada tabel yang kompleks.
  • Menggunakan td untuk semua sel termasuk header.
  • Membuat tabel sangat lebar tanpa memikirkan layar ponsel.

Latihan

Buat tabel daftar produk dengan kolom Nama, Harga, dan Stok. Tambahkan caption, thead, dua baris data, serta scope pada setiap header.

Rangkuman

Tabel cocok untuk data tabular. Struktur semantik dan atribut scope membuat hubungan data lebih jelas untuk semua pengguna.
