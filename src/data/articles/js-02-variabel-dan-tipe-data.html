Variabel adalah kotak bernama untuk menyimpan nilai agar dapat dipakai lagi. Setiap nilai memiliki tipe, misalnya teks, angka, atau benar/salah.

Tujuan Belajar

  • Membuat variabel dengan let dan const.
  • Mengenal tipe data dasar JavaScript.
  • Memeriksa dan mengubah tipe data.

1. let dan const

const nama = "Sinta";   // nilai tidak akan diganti
let umur = 20;           // nilai boleh diganti

umur = 21;               // boleh
// nama = "Budi";        // Error: const tidak bisa diisi ulang

console.log(nama, umur);

Gunakan const sebagai pilihan awal. Pakai let hanya bila nilainya memang akan berubah. Hindari var karena aturannya membingungkan dan sudah jarang dipakai.

2. Aturan Penamaan

  • Boleh berisi huruf, angka, _, dan $, tetapi tidak boleh diawali angka.
  • Huruf besar-kecil dibedakan: nama dan Nama adalah dua variabel.
  • Gunakan gaya camelCase: namaLengkap, totalHarga.
  • Pilih nama yang menjelaskan isi, bukan x atau data1.

3. Tipe Data Dasar

const teks = "Halo";        // string
const harga = 15000;        // number
const desimal = 3.14;       // number juga
const aktif = true;         // boolean
const kosong = null;        // sengaja dikosongkan
let belumDiisi;             // undefined

console.log(typeof teks);   // "string"
console.log(typeof harga);  // "number"
console.log(typeof aktif);  // "boolean"
console.log(typeof belumDiisi); // "undefined"

typeof memberi tahu tipe sebuah nilai. undefined berarti variabel belum diberi nilai, sedangkan null berarti Anda sengaja mengosongkannya.

4. Mengubah Tipe Data

console.log(Number("42") + 8);   // 50
console.log("42" + 8);           // "428" (digabung sebagai teks!)
console.log(String(123));        // "123"
console.log(Number("abc"));      // NaN (bukan angka)

Nilai dari input form selalu berupa teks, sehingga sering perlu diubah dengan Number() sebelum dihitung.

Kesalahan Umum

  • Mengubah variabel const.
  • Menjumlahkan angka dengan teks dan mendapatkan penggabungan, bukan penjumlahan.
  • Menulis angka dalam tanda kutip lalu heran saat hasilnya teks.

Latihan

Buat variabel untuk nama, umur, dan status mahasiswa. Cetak ketiganya beserta typeof-nya. Lalu hitung "10" + 5 dan Number("10") + 5, dan jelaskan perbedaannya.

Rangkuman

Gunakan const secara default dan let bila perlu mengganti nilai. Tipe dasar: string, number, boolean, null, dan undefined. Periksa dengan typeof dan ubah dengan Number() atau String().
