Fungsi adalah blok kode yang diberi nama dan dapat dipakai berulang kali. Dengan fungsi, program Anda lebih rapi, mudah diuji, dan tidak penuh salinan kode.

Tujuan Belajar

  • Membuat dan memanggil fungsi.
  • Memakai parameter, nilai default, dan return.
  • Menulis arrow function.

1. Membuat dan Memanggil Fungsi

function sapa(nama) {
  console.log("Halo, " + nama + "!");
}

sapa("Sinta");   // Halo, Sinta!
sapa("Budi");    // Halo, Budi!

nama adalah parameter (penampung), sedangkan "Sinta" adalah argumen (nilai yang dikirim).

2. return

function hitungLuas(panjang, lebar) {
  return panjang * lebar;
}

const luas = hitungLuas(5, 3);
console.log(luas); // 15

return mengirim nilai kembali ke pemanggil dan menghentikan fungsi. Fungsi tanpa return menghasilkan undefined.

3. Nilai Default Parameter

function salam(nama = "Teman") {
  return `Halo, ${nama}!`;
}

console.log(salam());        // Halo, Teman!
console.log(salam("Sinta")); // Halo, Sinta!

4. Function Expression dan Arrow Function

// function expression
const kali = function (a, b) {
  return a * b;
};

// arrow function
const tambah = (a, b) => a + b;
const kuadrat = (x) => x * x;
const sapaSingkat = () => "Halo!";

console.log(kali(2, 3), tambah(2, 3), kuadrat(4), sapaSingkat());

Bila badan arrow function hanya satu ekspresi, return boleh dihilangkan. Jika memakai kurung kurawal { }, Anda harus menulis return secara eksplisit.

5. Fungsi sebagai Nilai

Fungsi dapat disimpan di variabel dan dikirim ke fungsi lain. Ini disebut callback dan akan sangat sering dipakai pada event dan array.

function ulangi(kali, aksi) {
  for (let i = 0; i < kali; i++) aksi(i);
}

ulangi(3, (i) => console.log("Aksi ke-" + i));

Kesalahan Umum

  • Lupa memanggil fungsi (sapa tanpa tanda kurung hanya menyebut fungsinya).
  • Lupa return sehingga hasilnya undefined.
  • Membuat fungsi yang melakukan terlalu banyak hal. Satu fungsi sebaiknya satu tugas.

Latihan

Buat fungsi hitungDiskon(harga, persen) yang mengembalikan harga akhir, lalu tulis ulang sebagai arrow function. Buat juga fungsi apakahGenap(angka) yang mengembalikan boolean.

Rangkuman

Fungsi menerima parameter dan dapat mengembalikan nilai dengan return. Arrow function adalah penulisan ringkas, dan fungsi bisa diperlakukan sebagai nilai biasa.
