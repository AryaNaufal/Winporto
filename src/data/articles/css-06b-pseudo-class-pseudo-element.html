Pseudo-class memilih elemen berdasarkan keadaan, sedangkan pseudo-element memilih atau membuat bagian virtual dari elemen.

1. Demo Interaksi dan Dekorasi

<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <style>
    body {
      font-family: Arial, sans-serif;
      padding: 32px;
      color: #334155;
    }

    .judul::after {
      content: "";
      display: block;
      width: 48px;
      height: 4px;
      margin-top: 8px;
      background-color: #14b8a6;
    }

    .tombol {
      display: inline-block;
      padding: 12px 18px;
      color: white;
      background-color: #0f766e;
      border-radius: 8px;
      text-decoration: none;
    }

    .tombol::after {
      content: " →";
      display: inline-block;
      transition: transform 180ms ease;
    }

    .tombol:hover {
      background-color: #115e59;
    }

    .tombol:hover::after {
      transform: translateX(4px);
    }

    .tombol:focus-visible {
      outline: 3px solid #2dd4bf;
      outline-offset: 3px;
    }

    input:checked {
      accent-color: #0f766e;
    }

    li:first-child {
      font-weight: 700;
    }

    li:nth-child(even) {
      background-color: #f1f5f9;
    }
  </style>
</head>
<body>
  <h1 class="judul">Pseudo-Class dan Pseudo-Element</h1>
  <a class="tombol" href="#contoh">Lihat contoh</a>

  <p><label><input type="checkbox"> Tandai materi selesai</label></p>

  <ol id="contoh">
    <li>Item pertama dibuat tebal.</li>
    <li>Item genap memiliki background.</li>
    <li>Item ketiga tampil biasa.</li>
    <li>Item genap memiliki background.</li>
  </ol>
</body>
</html>

:hover, :focus-visible, :checked, dan :first-child adalah pseudo-class. ::before dan ::after adalah pseudo-element. Properti content wajib tersedia untuk keduanya, walaupun nilainya berupa teks kosong.

Jangan menghapus outline tanpa menyediakan pengganti yang terlihat. Informasi penting juga sebaiknya tetap ditulis di HTML, bukan hanya melalui content.

Kesalahan yang Sering Terjadi

  • Menulis button hover tanpa tanda titik dua.
  • Hanya menyediakan efek :hover dan melupakan :focus-visible.
  • Menaruh kalimat penting melalui content.
  • Membuat selector terlalu panjang sehingga sulit dirawat.

Latihan

Arahkan mouse ke tombol, lalu gunakan tombol Tab untuk memfokuskannya. Ubah jarak gerak panah dan tambahkan gaya untuk button:disabled.

Ringkasan

Pseudo-class memilih keadaan elemen, misalnya :hover dan :checked. Pseudo-element membuat bagian virtual, misalnya ::before dan ::after.
