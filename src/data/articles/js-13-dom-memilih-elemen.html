Inilah titik di mana JavaScript benar-benar bertemu halaman web. DOM (Document Object Model) adalah representasi halaman HTML sebagai pohon object yang dapat dibaca dan diubah oleh JavaScript.

Tujuan Belajar

  • Memahami DOM sebagai pohon elemen.
  • Memilih elemen dengan querySelector dan querySelectorAll.
  • Menelusuri elemen di sekitarnya.

1. Contoh HTML yang Dipakai

<h1 id="judul">Daftar Tugas</h1>
<ul class="daftar">
  <li class="item">Belajar HTML</li>
  <li class="item selesai">Belajar CSS</li>
  <li class="item">Belajar JavaScript</li>
</ul>
<script src="app.js" defer></script>

Browser mengubah HTML ini menjadi pohon: document memiliki h1 dan ul, lalu ul memiliki tiga li.

2. Memilih Satu Elemen

const judul = document.querySelector("#judul");      // berdasarkan id
const pertama = document.querySelector(".item");     // elemen .item PERTAMA
const daftar = document.getElementById("judul");     // cara lain berdasarkan id

console.log(judul.textContent);   // "Daftar Tugas"
console.log(pertama.textContent); // "Belajar HTML"

querySelector menerima selector CSS apa pun, sehingga pengetahuan CSS Anda langsung terpakai. Jika tidak ada yang cocok, hasilnya null.

3. Memilih Banyak Elemen

const semuaItem = document.querySelectorAll(".item");

console.log(semuaItem.length); // 3

semuaItem.forEach((item, indeks) => {
  console.log(indeks + 1, item.textContent);
});

const arr = [...semuaItem];   // ubah menjadi array bila perlu map/filter

4. Menelusuri Pohon

const daftar2 = document.querySelector(".daftar");

console.log(daftar2.children);               // semua anak elemen
console.log(daftar2.firstElementChild);      // anak pertama
console.log(daftar2.lastElementChild);       // anak terakhir
console.log(daftar2.parentElement);          // induk (body)

const item = document.querySelector(".item");
console.log(item.nextElementSibling);        // saudara berikutnya
console.log(item.closest(".daftar"));        // leluhur terdekat yang cocok

5. Jangan Lupa defer

Jika skrip berjalan sebelum elemennya dibuat, querySelector mengembalikan null. Pasang defer atau letakkan skrip di akhir <body>.

Kesalahan Umum

  • Lupa tanda # atau . pada selector.
  • Menjalankan skrip sebelum HTML dimuat sehingga hasilnya null.
  • Memakai querySelector padahal butuh semua elemen (pakai querySelectorAll).

Latihan

Gunakan HTML di atas. Cetak teks setiap li ke Console, lalu temukan li yang punya class selesai dan cetak teks saudara sebelumnya.

Rangkuman

DOM adalah pohon elemen halaman. querySelector memilih satu elemen, querySelectorAll memilih semuanya, dan properti seperti children dan parentElement membantu menelusuri.
