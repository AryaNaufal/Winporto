List digunakan ketika beberapa informasi merupakan satu kelompok, misalnya daftar belanja, langkah memasak, atau menu navigasi.

Tujuan Belajar

  • Memilih ul atau ol berdasarkan makna.
  • Menulis item dengan li.
  • Membuat list bersarang dengan struktur yang valid.
  • Menggunakan description list untuk pasangan istilah dan penjelasan.

1. Unordered List

Gunakan <ul> jika urutan item tidak mengubah makna.

<h2>Bahan</h2>
<ul>
  <li>Tepung</li>
  <li>Gula</li>
  <li>Telur</li>
</ul>

Bullet hanyalah tampilan bawaan. Bentuk bullet dapat diubah dengan CSS tanpa mengganti makna list.

2. Ordered List

Gunakan <ol> jika urutan penting.

<h2>Langkah Membuat Teh</h2>
<ol>
  <li>Didihkan air.</li>
  <li>Masukkan teh ke cangkir.</li>
  <li>Tuangkan air panas.</li>
</ol>

Jangan menggunakan ul lalu mengetik angka secara manual. Jika item ditambah, nomor manual mudah menjadi salah.

3. List Bersarang

List anak harus berada di dalam sebuah li.

<ul>
  <li>
    Front-end
    <ul>
      <li>HTML</li>
      <li>CSS</li>
    </ul>
  </li>
  <li>Back-end</li>
</ul>

Hindari terlalu banyak tingkat karena pembaca akan kesulitan mengikuti struktur.

4. Description List

Gunakan <dl> untuk pasangan istilah dan deskripsi.

<dl>
  <dt>HTML</dt>
  <dd>Bahasa untuk menyusun struktur halaman.</dd>

  <dt>CSS</dt>
  <dd>Bahasa untuk mengatur tampilan halaman.</dd>
</dl>

dt adalah istilah dan dd adalah penjelasannya. Description list bukan pengganti tabel data.

Kesalahan Umum

  • Menulis li tanpa pembungkus ul atau ol.
  • Memakai list hanya untuk membuat indentasi.
  • Meletakkan list anak sebagai saudara li, bukan di dalamnya.

Latihan

Buat halaman resep dengan unordered list untuk bahan, ordered list untuk langkah, dan description list untuk menjelaskan tiga istilah memasak.

Rangkuman

Pilih list berdasarkan hubungan antaritem: ul untuk kelompok tanpa urutan, ol untuk langkah berurutan, dan dl untuk istilah beserta penjelasan. Tabel data dibahas terpisah pada pelajaran HTML 7.
