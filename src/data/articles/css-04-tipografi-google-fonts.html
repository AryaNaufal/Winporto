Tipografi adalah cara teks disusun agar nyaman dibaca. Font yang menarik tidak akan membantu jika ukuran terlalu kecil, baris terlalu rapat, atau paragraf terlalu lebar.

1. Contoh Tipografi Artikel

<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
  <link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;700&display=swap" rel="stylesheet">

  <style>
    body {
      margin: 0;
      padding: 32px 20px;
      font-family: Inter, Arial, sans-serif;
      font-size: 1rem;
      line-height: 1.7;
      color: #334155;
      background-color: #f8fafc;
    }

    .artikel {
      max-width: 68ch;
      margin-inline: auto;
      padding: 28px;
      background-color: white;
      border-radius: 16px;
    }

    .label {
      color: #0f766e;
      font-size: 0.75rem;
      font-weight: 700;
      letter-spacing: 0.08em;
      text-transform: uppercase;
    }

    h1 {
      margin-block: 8px 16px;
      color: #0f172a;
      font-size: 2.25rem;
      line-height: 1.2;
      font-weight: 700;
    }
  </style>
</head>
<body>
  <article class="artikel">
    <span class="label">Web Development</span>
    <h1>Tipografi yang Nyaman Dibaca</h1>
    <p>
      Panjang baris dan jarak antarbaris membantu mata mengikuti teks.
      Font yang baik harus mendukung isi, bukan mengalahkan isi.
    </p>
    <p>
      Kecilkan dan lebarkan viewport untuk melihat bagaimana batas 68ch
      menjaga paragraf agar tidak terlalu panjang.
    </p>
  </article>
</body>
</html>

Browser mencoba font pada font-family dari kiri ke kanan. Jika Inter gagal dimuat, Arial digunakan, lalu font sans-serif bawaan sistem.

2. Ukuran, Ketebalan, dan Line Height

line-height tanpa unit mudah menyesuaikan ukuran font turunannya. Paragraf biasanya membutuhkan jarak baris lebih longgar daripada heading. Tidak semua font menyediakan semua font-weight, jadi muat hanya weight yang benar-benar digunakan.

3. Panjang Baris

Unit ch mendekati lebar karakter. max-width: 68ch menjaga paragraf agar tidak membentang selebar monitor. Teks panjang rata kiri umumnya juga lebih mudah diikuti daripada rata tengah.

4. Web Font

Elemen <link> pada contoh memuat Inter dari Google Fonts. Web font membutuhkan koneksi internet, sehingga fallback tetap wajib. Terlalu banyak family dan weight dapat memperlambat halaman; font sistem sering cukup untuk desain sederhana.

Kesalahan Umum

  • Tidak menyediakan fallback.
  • Memakai font tipis untuk paragraf panjang.
  • Membuat paragraf terlalu lebar.
  • Memuat banyak family dan weight yang tidak digunakan.
  • Menggunakan ukuran teks yang terlalu kecil.

Latihan

Ubah line-height menjadi 1 lalu bandingkan keterbacaannya. Kembalikan ke 1.7, ubah batas artikel menjadi 40ch, dan coba font fallback dengan menghapus elemen Google Fonts.

Rangkuman

Tipografi yang baik mengutamakan keterbacaan. Gunakan font stack, hirarki ukuran, line-height yang cukup, panjang baris terkendali, dan web font secukupnya.
