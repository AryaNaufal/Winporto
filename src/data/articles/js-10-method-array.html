Selain loop, array punya method yang memproses seluruh isinya secara ringkas: mengubah bentuk, menyaring, mencari, dan menghitung. Method ini adalah pekerjaan sehari-hari developer JavaScript.

Tujuan Belajar

  • Memakai forEach, map, dan filter.
  • Memakai find, some, every, dan reduce.
  • Mengurutkan array dengan benar.

1. forEach

const angka = [1, 2, 3];
angka.forEach((n) => console.log(n * 10)); // 10, 20, 30

forEach menjalankan fungsi untuk setiap item dan tidak mengembalikan apa pun.

2. map: Mengubah Setiap Item

const harga = [10000, 25000, 40000];
const denganPajak = harga.map((h) => h * 1.1);
console.log(denganPajak); // [11000, 27500, 44000]

map menghasilkan array baru dengan jumlah item yang sama.

3. filter: Menyaring Item

const nilai = [55, 80, 67, 92, 40];
const lulus = nilai.filter((n) => n >= 60);
console.log(lulus); // [80, 67, 92]

4. find, some, every

const produk = [
  { nama: "Pensil", stok: 0 },
  { nama: "Buku", stok: 12 },
  { nama: "Penghapus", stok: 5 },
];

console.log(produk.find((p) => p.stok > 10));        // { nama: "Buku", stok: 12 }
console.log(produk.some((p) => p.stok === 0));        // true  (ada yang habis)
console.log(produk.every((p) => p.stok > 0));         // false (tidak semua tersedia)

5. reduce: Merangkum Jadi Satu Nilai

const belanja = [15000, 20000, 5000];
const total = belanja.reduce((jumlah, harga) => jumlah + harga, 0);
console.log(total); // 40000

Argumen kedua (0) adalah nilai awal. Pada setiap putaran, hasil dikirim kembali sebagai jumlah.

6. sort dan Rantai Method

const skor = [100, 9, 25, 4];

skor.sort();                   // [100, 25, 4, 9]  SALAH: diurutkan sebagai teks
skor.sort((a, b) => a - b);    // [4, 9, 25, 100]  urut naik
skor.sort((a, b) => b - a);    // [100, 25, 9, 4]  urut turun

// Merangkai method
const hasil = [1, 2, 3, 4, 5, 6]
  .filter((n) => n % 2 === 0)
  .map((n) => n * n);
console.log(hasil); // [4, 16, 36]

sort mengubah array aslinya. Untuk menjaga aslinya, salin dulu: [...skor].sort(...).

Kesalahan Umum

  • Memakai map padahal hanya butuh efek samping (gunakan forEach).
  • Lupa menulis return pada arrow function bertanda kurung kurawal.
  • Memakai sort() tanpa fungsi pembanding untuk angka.

Latihan

Dari daftar harga [12000, 8000, 45000, 30000]: ambil harga di atas 10000, beri diskon 10%, lalu jumlahkan semuanya dengan satu rantai method.

Rangkuman

map mengubah, filter menyaring, find mencari satu, some/every memeriksa kondisi, reduce merangkum, dan sort mengurutkan dengan fungsi pembanding.
