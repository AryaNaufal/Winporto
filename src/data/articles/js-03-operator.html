Operator adalah simbol yang melakukan sesuatu pada nilai: menghitung, membandingkan, atau menggabungkan kondisi. Operator adalah dasar dari hampir setiap keputusan dalam program.

Tujuan Belajar

  • Menghitung dengan operator aritmetika.
  • Membandingkan nilai dengan benar menggunakan ===.
  • Menggabungkan kondisi dengan operator logika.

1. Operator Aritmetika

console.log(10 + 3);   // 13
console.log(10 - 3);   // 7
console.log(10 * 3);   // 30
console.log(10 / 3);   // 3.3333333333333335
console.log(10 % 3);   // 1  (sisa bagi)
console.log(2 ** 3);   // 8  (pangkat)

Operator % (modulus) berguna untuk memeriksa bilangan genap: angka % 2 === 0.

2. Operator Penugasan

let skor = 10;
skor += 5;   // sama dengan skor = skor + 5  -> 15
skor -= 2;   // 13
skor *= 2;   // 26
skor++;      // 27 (tambah 1)
skor--;      // 26 (kurang 1)

3. Operator Perbandingan

console.log(5 > 3);        // true
console.log(5 <= 3);       // false
console.log(5 === 5);      // true
console.log(5 === "5");    // false (tipe berbeda)
console.log(5 == "5");     // true  (JavaScript mengubah tipe diam-diam)
console.log(5 !== 6);      // true

Selalu gunakan === dan !==. Operator == mengubah tipe secara otomatis dan sering memberi hasil yang mengejutkan.

4. Operator Logika

const umur = 20;
const punyaKtp = true;

console.log(umur >= 17 && punyaKtp);  // true  (keduanya harus benar)
console.log(umur < 17 || punyaKtp);   // true  (salah satu cukup)
console.log(!punyaKtp);               // false (kebalikan)
  • && (DAN): benar bila kedua sisi benar.
  • || (ATAU): benar bila salah satu benar.
  • ! (BUKAN): membalik benar menjadi salah.

Kesalahan Umum

  • Memakai = (penugasan) padahal maksudnya === (perbandingan).
  • Memakai == sehingga 0 == "" bernilai true.
  • Lupa kurung pada ekspresi panjang sehingga urutan hitung tidak sesuai harapan.

Latihan

Tulis ekspresi yang bernilai true jika sebuah angka genap dan lebih besar dari 10. Uji dengan beberapa angka di Console.

Rangkuman

Aritmetika menghitung, += dan ++ memperbarui nilai, === membandingkan dengan aman, dan &&, ||, ! menggabungkan kondisi.
