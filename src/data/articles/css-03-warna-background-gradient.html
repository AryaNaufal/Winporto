Warna digunakan pada teks, border, latar, ikon, dan banyak bagian lain. Tujuannya bukan menghafal kode warna, tetapi memahami format dan memilih warna yang tetap terbaca.

1. Format Warna dalam Satu Contoh

<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <style>
    body {
      font-family: Arial, sans-serif;
      padding: 24px;
      color: #1e293b;
      background-color: rgb(248 250 252);
    }

    .daftar-warna {
      display: flex;
      flex-wrap: wrap;
      gap: 12px;
    }

    .warna {
      padding: 20px;
      color: white;
      border-radius: 10px;
    }

    .named { background-color: teal; }
    .hex { background-color: #2563eb; }
    .rgb { background-color: rgb(147 51 234); }
    .hsl { background-color: hsl(24 95% 53%); }

    .transparan {
      margin-top: 16px;
      padding: 20px;
      color: #0f172a;
      background-color: rgb(20 184 166 / 25%);
      border: 2px solid rgb(20 184 166 / 70%);
    }
  </style>
</head>
<body>
  <h1>Format Warna CSS</h1>
  <div class="daftar-warna">
    <div class="warna named">Named color</div>
    <div class="warna hex">HEX</div>
    <div class="warna rgb">RGB</div>
    <div class="warna hsl">HSL</div>
  </div>
  <div class="transparan">Kotak ini menggunakan transparansi alpha.</div>
</body>
</html>
  • Named color mudah dibaca tetapi pilihannya terbatas.
  • HEX memakai format #RRGGBB.
  • RGB menulis nilai merah, hijau, dan biru.
  • HSL menulis hue, saturation, dan lightness.
  • Alpha mengatur tingkat transparansi.

HSL nyaman ketika Anda ingin membuat warna hover yang lebih gelap dengan mengubah nilai lightness.

2. currentColor dan Keadaan Hover

<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <style>
    body {
      font-family: Arial, sans-serif;
      padding: 32px;
    }

    .tautan {
      display: inline-block;
      padding: 10px 16px;
      color: hsl(173 80% 32%);
      border: 2px solid currentColor;
      border-radius: 8px;
      text-decoration: none;
    }

    .tautan:hover {
      color: hsl(173 80% 24%);
      background-color: hsl(173 80% 94%);
    }

    .error {
      margin-top: 20px;
      padding: 12px;
      color: #991b1b;
      border-left: 4px solid currentColor;
      background-color: #fef2f2;
    }
  </style>
</head>
<body>
  <a class="tautan" href="#">Pelajari lebih lanjut</a>
  <p class="error"><strong>Error:</strong> Email tidak valid.</p>
</body>
</html>

currentColor mengambil nilai color elemen saat ini sehingga border mengikuti warna teks. Pesan error juga memakai kata “Error”, bukan warna merah saja, agar maknanya tetap jelas.

Kesalahan Umum

  • Memilih teks abu-abu terlalu muda di atas latar putih.
  • Menggunakan warna sebagai satu-satunya penanda keadaan.
  • Memakai alpha tanpa memeriksa warna di belakangnya.
  • Mencampur terlalu banyak format warna tanpa alasan.

Latihan

Jalankan contoh pertama, lalu buat satu kotak baru menggunakan HEX. Tambahkan keadaan hover menggunakan HSL dan pastikan teks tetap mudah dibaca.

Rangkuman

CSS menyediakan beberapa format warna yang sama-sama valid. Pilih format yang mudah dipelihara, gunakan alpha dengan sadar, dan selalu prioritaskan kontras. Background dan gradient dibahas pada pelajaran CSS 9.
