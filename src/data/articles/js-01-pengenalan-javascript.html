JavaScript adalah bahasa pemrograman yang membuat halaman web hidup dan interaktif. HTML menyusun isi halaman, CSS mengatur tampilannya, sedangkan JavaScript mengatur perilakunya: menanggapi klik, memeriksa form, menampilkan data, dan banyak lagi.

Tujuan Belajar

  • Memahami peran JavaScript dibanding HTML dan CSS.
  • Menjalankan JavaScript pertama di halaman web.
  • Memakai Console browser untuk melihat hasil dan error.

1. JavaScript Pertama

Kode JavaScript ditulis di dalam elemen <script>. Letakkan di akhir <body> agar HTML sudah dimuat lebih dulu.

<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <title>JavaScript Pertama</title>
</head>
<body>
  <h1>Halo Dunia</h1>
  <script>
    console.log("Halo dari JavaScript!");
    alert("Selamat datang!");
  </script>
</body>
</html>

console.log() menulis pesan ke Console, sedangkan alert() menampilkan kotak dialog. Console jauh lebih berguna untuk belajar dan memeriksa program.

2. File JavaScript Terpisah

Untuk project sungguhan, simpan kode di file .js lalu hubungkan dengan src. Atribut defer membuat browser menjalankan skrip setelah HTML selesai dibaca, sehingga skrip boleh diletakkan di <head>.

<script src="app.js" defer></script>

// app.js
console.log("File app.js berhasil dimuat");

3. Membuka Console Browser

Tekan F12 (atau klik kanan lalu Inspect), kemudian buka tab Console. Pesan dari console.log dan pesan error muncul di sini. Anda juga dapat mengetik kode langsung, misalnya 2 + 3, lalu menekan Enter.

4. Komentar dan Titik Koma

// Komentar satu baris
/* Komentar
   beberapa baris */
console.log("Baris ini dijalankan"); // titik koma mengakhiri perintah

Titik koma di akhir perintah dianjurkan agar konsisten. Yang terpenting, pilih satu gaya dan gunakan terus.

Kesalahan Umum

  • Lupa menutup tanda kutip atau kurung.
  • Salah menulis huruf besar-kecil: Console.log tidak sama dengan console.log.
  • Salah nama file pada src, sehingga skrip tidak dimuat (periksa tab Console atau Network).

Latihan

Buat file index.html dan app.js. Tampilkan nama Anda di Console dengan console.log, lalu sengaja hapus satu tanda kutip dan baca pesan error yang muncul.

Rangkuman

JavaScript menambahkan perilaku pada halaman. Jalankan lewat <script>, lebih baik lewat file terpisah dengan defer, dan gunakan Console untuk melihat hasil serta error.
