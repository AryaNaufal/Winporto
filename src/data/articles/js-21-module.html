Seiring bertambahnya fitur, satu file JavaScript menjadi panjang dan membingungkan. Module memungkinkan Anda memecah kode menjadi file-file kecil yang masing-masing punya tugas jelas dan saling mengimpor.

Tujuan Belajar

  • Mengekspor dan mengimpor fungsi antarfile.
  • Membedakan named export dan default export.
  • Memuat module di HTML.

1. Struktur Project

proyek/
  index.html
  main.js
  utils/
    format.js
    storage.js

2. Named Export

// utils/format.js
export function formatRupiah(angka) {
  return new Intl.NumberFormat("id-ID", {
    style: "currency",
    currency: "IDR",
    maximumFractionDigits: 0,
  }).format(angka);
}

export const PPN = 0.11;

// main.js
import { formatRupiah, PPN } from "./utils/format.js";

console.log(formatRupiah(15000 * (1 + PPN))); // Rp16.650

Nama yang diimpor harus sama dengan yang diekspor, dan wajib ditulis di dalam kurung kurawal. Sertakan ekstensi .js pada path.

3. Default Export

// utils/storage.js
export default function simpan(kunci, nilai) {
  localStorage.setItem(kunci, JSON.stringify(nilai));
}

// main.js
import simpan from "./utils/storage.js";   // tanpa kurung kurawal, nama bebas
simpan("tema", "gelap");

Satu file hanya boleh memiliki satu default export, tetapi boleh memiliki banyak named export.

4. Mengganti Nama dan Mengimpor Semua

import { formatRupiah as rupiah } from "./utils/format.js";
import * as format from "./utils/format.js";

console.log(rupiah(5000), format.PPN);

5. Memuat Module di HTML

<script type="module" src="main.js"></script>
  • Skrip type="module" otomatis ditunda seperti defer.
  • Setiap module punya scope sendiri: variabelnya tidak bocor ke global.
  • Module tidak berjalan bila HTML dibuka langsung lewat file://. Gunakan server lokal, misalnya ekstensi Live Server di VS Code.

Kesalahan Umum

  • Lupa type="module" sehingga muncul error Cannot use import statement outside a module.
  • Lupa ekstensi .js atau salah path relatif (./).
  • Membuka file langsung tanpa server lokal.

Latihan

Pecah proyek daftar tugas menjadi tiga file: storage.js (simpan dan muat), ui.js (render daftar), dan main.js (menyambungkan semuanya).

Rangkuman

Module memecah kode ke banyak file. Gunakan export dan import, tulis type="module" di HTML, dan jalankan lewat server lokal.
