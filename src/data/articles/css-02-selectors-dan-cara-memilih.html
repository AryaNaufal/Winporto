Selector menentukan elemen HTML mana yang menerima sebuah aturan. Selector yang baik cukup spesifik untuk tujuan kita, tetapi tetap mudah digunakan ulang.

1. Selector Elemen, Class, dan ID

Jalankan contoh berikut dan cocokkan setiap selector dengan elemen pada bagian <body>.

<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <style>
    body {
      font-family: Arial, sans-serif;
      padding: 24px;
      color: #334155;
    }

    /* Selector elemen: memilih semua paragraf */
    p {
      line-height: 1.7;
    }

    /* Selector class: dapat digunakan berulang kali */
    .peringatan {
      padding: 12px;
      color: #991b1b;
      background-color: #fee2e2;
      border-radius: 8px;
    }

    /* Selector ID: hanya untuk identitas unik */
    #kontak {
      margin-top: 24px;
      padding: 16px;
      background-color: #ccfbf1;
    }
  </style>
</head>
<body>
  <h1>Jenis Selector</h1>
  <p>Paragraf biasa dipilih oleh selector elemen.</p>
  <p class="peringatan">Data akan dihapus permanen.</p>
  <p class="peringatan">Tindakan tidak dapat dibatalkan.</p>

  <section id="kontak">
    <h2>Kontak</h2>
    <p>Email: halo@example.com</p>
  </section>
</body>
</html>

Class diawali titik dan dapat digunakan pada banyak elemen. ID diawali # dan harus unik dalam satu halaman. Untuk styling yang dapat digunakan ulang, class biasanya lebih fleksibel.

2. Grouping, Descendant, dan Child

Koma berarti memilih beberapa selector. Spasi memilih semua keturunan, sedangkan > hanya memilih anak langsung.

<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <style>
    body {
      font-family: Arial, sans-serif;
      padding: 24px;
    }

    h1,
    h2,
    h3 {
      font-family: Georgia, serif;
      color: #0f766e;
    }

    .artikel p {
      color: #475569;
    }

    .artikel > h2 {
      padding-bottom: 8px;
      border-bottom: 2px solid #5eead4;
    }
  </style>
</head>
<body>
  <h1>Blog Belajar</h1>

  <article class="artikel">
    <h2>Memahami Selector</h2>
    <p>Paragraf ini adalah anak langsung artikel.</p>
    <div>
      <h3>Catatan Tambahan</h3>
      <p>Paragraf ini tetap keturunan artikel walaupun berada di dalam div.</p>
    </div>
  </article>
</body>
</html>

Perhatikan bahwa .artikel p mengenai kedua paragraf. .artikel > h2 hanya mengenai h2 yang menjadi anak langsung .artikel.

Kesalahan Umum

  • Lupa titik pada class atau pagar pada ID.
  • Menamai class berdasarkan warna seperti .teks-merah, padahal fungsi komponennya mungkin berubah.
  • Membuat selector sangat panjang dan sulit digunakan ulang.
  • Menggunakan ID untuk setiap elemen hanya agar selector terasa kuat.

Latihan

Tambahkan tiga kartu dengan class .kartu. Beri satu kartu class tambahan .unggulan. Gunakan grouping untuk menyamakan font heading, lalu gunakan descendant selector untuk paragraf di dalam kartu.

Rangkuman

Mulailah dari selector paling sederhana. Class adalah pilihan utama untuk pola berulang, ID untuk identitas unik, dan combinator untuk menjelaskan hubungan struktur. Konflik antarselector dibahas pada pelajaran CSS 8: Cascade, Inheritance, dan Specificity.
