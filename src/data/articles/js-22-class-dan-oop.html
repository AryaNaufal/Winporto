Class adalah cetak biru untuk membuat banyak object dengan bentuk dan perilaku yang sama. Ini adalah pengantar ke pemrograman berorientasi object (OOP).

Tujuan Belajar

  • Membuat class dengan constructor dan method.
  • Membuat object dari class dengan new.
  • Memakai pewarisan, getter, dan field privat.

1. Class Pertama

class Produk {
  constructor(nama, harga) {
    this.nama = nama;
    this.harga = harga;
  }

  info() {
    return `${this.nama} - Rp${this.harga}`;
  }

  beriDiskon(persen) {
    return this.harga - (this.harga * persen) / 100;
  }
}

const buku = new Produk("Buku", 25000);
const pena = new Produk("Pena", 5000);

console.log(buku.info());           // Buku - Rp25000
console.log(buku.beriDiskon(10));   // 22500

constructor berjalan otomatis saat new dipakai. this menunjuk ke object yang sedang dibuat atau dipakai.

2. Pewarisan (extends)

class ProdukDigital extends Produk {
  constructor(nama, harga, ukuranMb) {
    super(nama, harga);       // panggil constructor induk lebih dulu
    this.ukuranMb = ukuranMb;
  }

  info() {
    return `${super.info()} (${this.ukuranMb} MB)`;
  }
}

const ebook = new ProdukDigital("E-book JS", 49000, 12);
console.log(ebook.info());   // E-book JS - Rp49000 (12 MB)

Class anak mewarisi semua method induk dan boleh menimpanya. Gunakan pewarisan bila hubungannya benar-benar "adalah sebuah" (e-book adalah produk).

3. Getter dan Setter

class Lingkaran {
  constructor(jariJari) {
    this.jariJari = jariJari;
  }

  get luas() {
    return Math.PI * this.jariJari ** 2;
  }
}

const l = new Lingkaran(7);
console.log(l.luas.toFixed(2)); // 153.94 (dipakai seperti property, tanpa kurung)

4. Field Privat dan Static

class Rekening {
  #saldo = 0;                      // privat: hanya bisa diakses dari dalam class

  setor(jumlah) {
    if (jumlah <= 0) throw new Error("Jumlah harus positif");
    this.#saldo += jumlah;
  }

  get saldo() {
    return this.#saldo;
  }

  static dariAngka(angka) {        // dipanggil lewat nama class
    const r = new Rekening();
    r.setor(angka);
    return r;
  }
}

const r = Rekening.dariAngka(1000);
r.setor(500);
console.log(r.saldo);   // 1500
// r.#saldo = 0;        // Error: field privat

Kapan Memakai Class?

Class cocok bila Anda perlu banyak object sejenis yang menyimpan data sekaligus perilakunya. Untuk data sederhana, object biasa dan fungsi sudah cukup; jangan menambah kerumitan yang tidak dibutuhkan.

Kesalahan Umum

  • Lupa new saat membuat object.
  • Lupa memanggil super() pada constructor class anak.
  • Memakai pewarisan untuk hubungan yang sebenarnya "memiliki", bukan "adalah".

Latihan

Buat class Hewan dengan method bersuara(), lalu class Kucing dan Anjing yang mewarisinya dan menimpa method tersebut.

Rangkuman

Class membungkus data dan perilaku. constructor menyiapkan object, extends dan super menurunkan perilaku, getter mempermudah akses, dan # menyembunyikan data.
