Object menyimpan data berpasangan nama: nilai. Jika array cocok untuk daftar, object cocok untuk menggambarkan satu benda, misalnya seorang pengguna atau sebuah produk.

Tujuan Belajar

  • Membuat object dan mengakses propertinya.
  • Menambah, mengubah, dan menghapus property.
  • Memakai destructuring, spread, dan optional chaining.

1. Membuat dan Mengakses Object

const pengguna = {
  nama: "Sinta",
  umur: 20,
  aktif: true,
};

console.log(pengguna.nama);        // notasi titik
console.log(pengguna["umur"]);     // notasi kurung

const kunci = "aktif";
console.log(pengguna[kunci]);      // kurung berguna untuk nama dinamis

2. Mengubah Object

pengguna.umur = 21;          // ubah
pengguna.kota = "Jakarta";   // tambah
delete pengguna.aktif;       // hapus
console.log(pengguna);

3. Method di Dalam Object

const kucing = {
  nama: "Mimi",
  bersuara() {
    return `${this.nama} berkata meong`;
  },
};

console.log(kucing.bersuara());

Di dalam method, this menunjuk ke object pemiliknya. Hindari arrow function untuk method object karena this-nya berbeda.

4. Mengambil Kunci, Nilai, dan Pasangan

const produk = { nama: "Buku", harga: 25000 };

console.log(Object.keys(produk));    // ["nama", "harga"]
console.log(Object.values(produk));  // ["Buku", 25000]

for (const [kunci, nilai] of Object.entries(produk)) {
  console.log(`${kunci}: ${nilai}`);
}

5. Destructuring dan Spread

const { nama, harga } = produk;           // ambil beberapa property
const { nama: judul } = produk;           // ganti nama variabel
const diskon = { ...produk, harga: 20000 }; // salinan dengan perubahan

console.log(nama, harga, judul, diskon);

6. Optional Chaining

const user = { profil: { alamat: { kota: "Bandung" } } };
const tamu = {};

console.log(user.profil.alamat.kota);   // "Bandung"
console.log(tamu.profil?.alamat?.kota); // undefined (tanpa error)
console.log(tamu.profil?.alamat?.kota ?? "Tidak diketahui");

?. berhenti dengan aman bila bagian di depannya null atau undefined, sedangkan ?? memberi nilai cadangan.

7. Array berisi Object

const siswa = [
  { nama: "Ani", nilai: 90 },
  { nama: "Budi", nilai: 70 },
];
console.log(siswa.filter((s) => s.nilai >= 80).map((s) => s.nama)); // ["Ani"]

Kesalahan Umum

  • Membaca property yang tidak ada lalu mengaksesnya lebih dalam (error: cannot read properties of undefined).
  • Menyalin object dengan =, padahal hanya menyalin referensi.
  • Memakai arrow function untuk method yang butuh this.

Latihan

Buat object buku berisi judul, penulis, dan tahun. Tambahkan method info() yang mengembalikan kalimat ringkas. Lalu buat salinan dengan tahun yang berbeda memakai spread.

Rangkuman

Object menyimpan data berpasangan nama dan nilai. Akses dengan titik atau kurung, bongkar dengan destructuring, salin dengan spread, dan akses aman dengan ?..
