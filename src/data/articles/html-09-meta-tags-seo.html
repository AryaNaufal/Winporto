Meta tags berada di dalam head dan memberikan informasi tentang halaman. Sebagian informasi dibaca browser, mesin pencari, atau layanan lain, tetapi tidak tampil sebagai konten utama.

1. Metadata Wajib

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Belajar HTML untuk Pemula | Belajar Web</title>
</head>

charset membantu karakter seperti é atau emoji ditampilkan dengan benar. viewport membuat ukuran halaman mengikuti perangkat. title biasanya tampil pada tab browser dan dapat digunakan sebagai judul hasil pencarian.

2. Meta Description

<meta
  name="description"
  content="Pelajari HTML dari nol melalui penjelasan sederhana, contoh kode, dan latihan untuk pemula."
>

Description merangkum isi halaman. Mesin pencari dapat menggunakannya sebagai cuplikan, tetapi tidak selalu. Tulis ringkasan yang spesifik, bukan daftar kata kunci.

3. Canonical dan Robots

<link rel="canonical" href="https://example.com/belajar-html">
<meta name="robots" content="index, follow">

Canonical menunjukkan URL utama ketika konten serupa tersedia melalui beberapa alamat. Robots memberikan arahan pengindeksan, tetapi bukan mekanisme keamanan. Halaman rahasia tetap membutuhkan autentikasi.

4. HTML yang Membantu SEO

SEO bukan sekadar meta tags. Konten yang jelas jauh lebih penting:

  • gunakan satu judul utama yang menjelaskan halaman;
  • susun h2 dan h3 secara logis;
  • tulis link yang menjelaskan tujuan;
  • tambahkan alt pada gambar informatif;
  • gunakan elemen semantik;
  • berikan isi yang benar-benar menjawab kebutuhan pembaca.
<main>
  <article>
    <h1>Cara Membuat Dokumen HTML</h1>
    <p>Panduan ini menjelaskan struktur dasar HTML.</p>
    <h2>Menulis Bagian Head</h2>
    <p>Bagian head menyimpan metadata halaman.</p>
  </article>
</main>

Kesalahan Umum

  • Menulis title yang sama untuk semua halaman.
  • Memenuhi description dengan pengulangan kata kunci.
  • Mengira noindex dapat melindungi halaman admin.
  • Mengabaikan kualitas dan struktur konten.

Latihan

Buat metadata untuk halaman kursus HTML: title yang unik, description yang menjelaskan manfaat, viewport, charset, dan canonical.

Rangkuman

Metadata membantu browser dan mesin pencari memahami halaman, tetapi SEO yang sehat dimulai dari konten berguna dan struktur HTML yang jelas. Social card dibahas terpisah pada pelajaran HTML 15.
