Setiap programmer menemui error, termasuk yang berpengalaman. Yang membedakan adalah kemampuan membaca pesan error, mencari penyebabnya, dan menanganinya dengan tenang.

Tujuan Belajar

  • Membaca pesan error di Console.
  • Menangani error dengan try...catch dan throw.
  • Melacak bug memakai Console dan breakpoint.

1. Jenis Error yang Sering Muncul

  • SyntaxError: penulisan salah (kurung atau kutip tidak ditutup). Program tidak berjalan sama sekali.
  • ReferenceError: memakai variabel yang tidak ada (x is not defined).
  • TypeError: memakai nilai dengan cara yang salah, misalnya Cannot read properties of undefined.

Baca pesan dari atas: nama error, penjelasan, lalu nama file dan nomor baris tempat error terjadi. Klik tautan itu di Console untuk melompat ke kodenya.

2. try...catch...finally

try {
  const data = JSON.parse("bukan json");
  console.log(data);
} catch (error) {
  console.log("Terjadi masalah:", error.message);
} finally {
  console.log("Blok ini selalu dijalankan");
}

Kode di try dijalankan; bila error, loncat ke catch. Blok finally berjalan apa pun hasilnya, cocok untuk membersihkan sesuatu.

3. Melempar Error Sendiri

function bagi(a, b) {
  if (b === 0) {
    throw new Error("Pembagi tidak boleh nol");
  }
  return a / b;
}

try {
  console.log(bagi(10, 0));
} catch (error) {
  console.log(error.message);
}

Gunakan throw ketika fungsi menerima masukan yang tidak mungkin diproses. Jangan memakai try/catch untuk menyembunyikan bug yang seharusnya diperbaiki.

4. Teknik Debugging

const pesanan = [{ nama: "Kopi", harga: 15000 }, { nama: "Teh", harga: 8000 }];

console.log("pesanan:", pesanan);     // lihat isi variabel
console.table(pesanan);               // tampilan tabel yang rapi
console.error("Ini tampil merah");
console.warn("Ini peringatan");

// debugger;  // jika DevTools terbuka, program berhenti di baris ini

5. Memakai Breakpoint

  1. Buka DevTools (F12) lalu tab Sources.
  2. Klik nomor baris untuk memasang breakpoint.
  3. Muat ulang halaman; program berhenti di baris tersebut.
  4. Lihat nilai variabel dan lanjutkan satu langkah demi satu (Step over).

Langkah Mencari Bug

  1. Baca pesan error dengan teliti.
  2. Pastikan Anda bisa mengulang bug yang sama.
  3. Cetak nilai di sekitar baris yang mencurigakan.
  4. Persempit area masalah, ubah satu hal setiap kali, lalu uji lagi.

Kesalahan Umum

  • Mengabaikan pesan error dan langsung menebak.
  • Menulis catch kosong yang membuat error hilang diam-diam.
  • Mengubah banyak kode sekaligus sehingga sulit tahu mana yang memperbaiki.

Latihan

Sengaja buat tiga error (SyntaxError, ReferenceError, TypeError), baca pesan masing-masing, lalu perbaiki. Setelah itu buat fungsi ambilUmur(teks) yang melempar error bila hasilnya bukan angka.

Rangkuman

Pesan error memberi petunjuk jenis dan lokasi masalah. Tangani dengan try/catch, lempar error dengan throw, dan cari bug secara sistematis memakai console dan breakpoint.
