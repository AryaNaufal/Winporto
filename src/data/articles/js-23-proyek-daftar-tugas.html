Saatnya menggabungkan semuanya. Pada pelajaran penutup ini Anda membuat aplikasi Daftar Tugas yang bisa menambah, menyelesaikan, dan menghapus tugas, serta menyimpannya di browser.

Tujuan Belajar

  • Menyusun aplikasi kecil dari HTML, CSS, dan JavaScript.
  • Memisahkan data (state) dari tampilan.
  • Memakai event delegation dan localStorage dalam satu project.

1. Rancangan

  • Pengguna mengetik tugas, lalu menekan Enter atau tombol Tambah.
  • Klik tugas untuk menandai selesai, tombol Hapus untuk membuangnya.
  • Data disimpan di localStorage agar tidak hilang.

Pola utama: simpan semua data di satu array (state), ubah array itu lewat fungsi, lalu panggil render() untuk menggambar ulang tampilan.

4. JavaScript: State dan Penyimpanan

const KUNCI = "daftar-tugas";

function muat() {
  try {
    return JSON.parse(localStorage.getItem(KUNCI)) ?? [];
  } catch {
    return [];
  }
}

function simpan() {
  try {
    localStorage.setItem(KUNCI, JSON.stringify(tugas));
  } catch {
    /* penyimpanan tidak tersedia: aplikasi tetap berjalan */
  }
}

let tugas = muat();   // [{ id, teks, selesai }]

5. JavaScript: Mengubah Data

function tambah(teks) {
  tugas.push({ id: Date.now(), teks, selesai: false });
  perbarui();
}

function toggle(id) {
  const t = tugas.find((item) => item.id === id);
  if (t) t.selesai = !t.selesai;
  perbarui();
}

function hapus(id) {
  tugas = tugas.filter((item) => item.id !== id);
  perbarui();
}

function perbarui() {
  simpan();
  render();
}

6. JavaScript: Tampilan

const daftar = document.querySelector("#daftar");
const info = document.querySelector("#info");

function render() {
  daftar.innerHTML = "";

  tugas.forEach((t) => {
    const li = document.createElement("li");
    li.dataset.id = t.id;
    li.classList.toggle("selesai", t.selesai);

    const span = document.createElement("span");
    span.textContent = t.teks;

    const tombol = document.createElement("button");
    tombol.type = "button";
    tombol.textContent = "Hapus";
    tombol.dataset.aksi = "hapus";
    tombol.setAttribute("aria-label", `Hapus tugas: ${t.teks}`);

    li.append(span, tombol);
    daftar.append(li);
  });

  const sisa = tugas.filter((t) => !t.selesai).length;
  info.textContent = tugas.length
    ? `${sisa} dari ${tugas.length} tugas belum selesai`
    : "Belum ada tugas. Tambahkan yang pertama!";
}

7. JavaScript: Event

const form = document.querySelector("#form");
const input = document.querySelector("#teks");

form.addEventListener("submit", (event) => {
  event.preventDefault();
  const teks = input.value.trim();
  if (!teks) return;
  tambah(teks);
  input.value = "";
  input.focus();
});

// Event delegation: satu listener untuk semua item
daftar.addEventListener("click", (event) => {
  const li = event.target.closest("li");
  if (!li) return;
  const id = Number(li.dataset.id);

  if (event.target.dataset.aksi === "hapus") hapus(id);
  else toggle(id);
});

render();

8. Ide Pengembangan

  • Tombol filter: Semua, Aktif, Selesai.
  • Edit teks tugas dengan klik dua kali.
  • Pecah kode menjadi module (storage.js, ui.js, main.js).
  • Ambil tugas awal dari API dengan fetch.
  • Tampilkan tanggal pembuatan dengan Date.

Kesalahan Umum

  • Mengubah tampilan tetapi lupa mengubah data (atau sebaliknya). Selalu ubah state, lalu render().
  • Lupa mengubah dataset.id yang berupa teks menjadi angka.
  • Memakai innerHTML untuk teks buatan pengguna.

Latihan

Tambahkan tombol "Hapus yang selesai" yang membuang semua tugas bertanda selesai, lalu tambahkan filter Aktif dan Selesai.
