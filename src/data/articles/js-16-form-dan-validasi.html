Form adalah cara utama pengguna memberi data. JavaScript membantu membaca isinya, memeriksanya, dan memberi umpan balik yang jelas sebelum data dikirim.

Tujuan Belajar

  • Membaca nilai input dan FormData.
  • Membuat validasi sendiri dengan pesan error yang jelas.
  • Membuat pesan error yang aksesibel.

1. HTML Form

<form id="daftar" novalidate>
  <label for="email">Email</label>
  <input id="email" name="email" type="email" aria-describedby="email-error">
  <p id="email-error" role="alert"></p>

  <label for="umur">Umur</label>
  <input id="umur" name="umur" type="number">
  <p id="umur-error" role="alert"></p>

  <label><input type="checkbox" name="setuju"> Saya setuju</label>
  <button type="submit">Kirim</button>
</form>

novalidate mematikan pop-up validasi bawaan agar Anda dapat menampilkan pesan sendiri.

2. Membaca Nilai

const form = document.querySelector("#daftar");

form.addEventListener("submit", (event) => {
  event.preventDefault();

  const data = new FormData(form);
  const email = data.get("email").trim();
  const umur = Number(data.get("umur"));
  const setuju = data.get("setuju") === "on";

  console.log({ email, umur, setuju });
  // Object.fromEntries(data) mengubah semuanya jadi object sekaligus
});

Nilai input selalu berupa teks, sehingga angka perlu diubah dengan Number().

3. Validasi Sendiri

function validasi({ email, umur }) {
  const error = {};
  if (!email.includes("@")) error.email = "Email harus memuat tanda @.";
  if (!Number.isInteger(umur) || umur < 17) error.umur = "Umur minimal 17 tahun.";
  return error;
}

function tampilkanError(error) {
  document.querySelector("#email-error").textContent = error.email ?? "";
  document.querySelector("#umur-error").textContent = error.umur ?? "";
}

4. Menyatukan

form.addEventListener("submit", (event) => {
  event.preventDefault();
  const data = new FormData(form);
  const nilai = {
    email: data.get("email").trim(),
    umur: Number(data.get("umur")),
  };

  const error = validasi(nilai);
  tampilkanError(error);

  if (Object.keys(error).length === 0) {
    console.log("Data valid, siap dikirim:", nilai);
    form.reset();
  } else {
    // pindahkan fokus ke kolom pertama yang salah
    form.querySelector(`[name="${Object.keys(error)[0]}"]`).focus();
  }
});

5. Tips Aksesibilitas

  • Setiap input wajib punya <label>.
  • Hubungkan pesan error dengan aria-describedby dan beri role="alert".
  • Tulis pesan error yang menjelaskan cara memperbaikinya, bukan hanya "Salah".
  • Validasi di JavaScript hanya kemudahan; server tetap wajib memeriksa ulang data.

Kesalahan Umum

  • Lupa preventDefault() sehingga halaman memuat ulang.
  • Menjumlahkan nilai input tanpa mengubahnya menjadi angka.
  • Hanya memvalidasi di sisi browser.

Latihan

Tambahkan kolom kata sandi dengan syarat minimal 8 karakter dan harus memuat angka. Tampilkan pesan error di bawah kolomnya, dan kosongkan pesan saat input diperbaiki.

Rangkuman

Gunakan event submit, FormData, dan fungsi validasi sendiri. Tampilkan error yang jelas dan aksesibel, serta ingat bahwa validasi sungguhan tetap harus dilakukan di server.
