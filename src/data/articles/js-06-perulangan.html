Perulangan menjalankan sekumpulan perintah berkali-kali tanpa Anda menulisnya berulang. Dengan loop, mencetak 1 sampai 1000 sama mudahnya dengan mencetak 1 sampai 3.

Tujuan Belajar

  • Memakai for, while, dan do...while.
  • Mengontrol loop dengan break dan continue.
  • Mengenal for...of untuk daftar nilai.

1. Loop for

for (let i = 1; i <= 5; i++) {
  console.log("Putaran ke-" + i);
}

Tiga bagian dalam kurung: awal (let i = 1), syarat lanjut (i <= 5), dan langkah (i++).

2. Loop while dan do...while

let hitung = 3;
while (hitung > 0) {
  console.log(hitung);
  hitung--;
}
console.log("Selesai!");

// do...while selalu berjalan minimal satu kali
let n = 10;
do {
  console.log("Dijalankan sekali, n =", n);
} while (n < 5);

Gunakan while ketika Anda tidak tahu berapa kali putaran dibutuhkan. Pastikan ada sesuatu di dalam loop yang akhirnya membuat syarat menjadi salah.

3. break dan continue

for (let i = 1; i <= 10; i++) {
  if (i === 3) continue;  // lewati putaran ini
  if (i === 6) break;     // hentikan seluruh loop
  console.log(i);         // 1, 2, 4, 5
}

4. for...of

const buah = ["apel", "jeruk", "mangga"];

for (const item of buah) {
  console.log(item);
}

Untuk membaca setiap isi daftar, for...of lebih ringkas dan lebih sulit salah dibanding for biasa dengan indeks.

5. Loop Bersarang

for (let baris = 1; baris <= 3; baris++) {
  let teks = "";
  for (let kolom = 1; kolom <= 3; kolom++) {
    teks += baris * kolom + " ";
  }
  console.log(teks);
}

Kesalahan Umum

  • Loop tak berhingga: lupa mengubah variabel yang diperiksa, sehingga halaman macet.
  • Off-by-one: memakai < padahal perlu <= (atau sebaliknya).
  • Memakai var pada loop, bukan let.

Latihan

Cetak semua bilangan genap dari 2 sampai 20. Kemudian hitung jumlah angka 1 sampai 100 dengan loop, lalu cetak tabel perkalian 5.

Rangkuman

for untuk jumlah putaran yang pasti, while untuk yang tidak pasti, for...of untuk membaca isi daftar. break keluar dari loop dan continue melewati satu putaran.
