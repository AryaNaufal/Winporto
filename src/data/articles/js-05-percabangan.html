Program yang berguna perlu mengambil keputusan: jika kondisi tertentu terpenuhi, lakukan A; jika tidak, lakukan B. Inilah percabangan.

Tujuan Belajar

  • Menulis if, else if, dan else.
  • Memahami nilai truthy dan falsy.
  • Memakai switch dan operator ternary.

1. if, else if, else

const nilai = 78;

if (nilai >= 85) {
  console.log("Sangat baik");
} else if (nilai >= 70) {
  console.log("Baik");
} else {
  console.log("Perlu belajar lagi");
}

JavaScript memeriksa kondisi dari atas ke bawah dan menjalankan blok pertama yang benar, lalu melewati sisanya.

2. Truthy dan Falsy

Dalam kondisi if, nilai non-boolean diperlakukan sebagai benar atau salah. Nilai falsy hanya: false, 0, "", null, undefined, dan NaN. Selain itu truthy.

const nama = "";

if (nama) {
  console.log("Halo, " + nama);
} else {
  console.log("Nama belum diisi");  // string kosong dianggap falsy
}

3. switch

Cocok bila satu nilai dibandingkan dengan banyak kemungkinan.

const hari = 3;
let namaHari;

switch (hari) {
  case 1:
    namaHari = "Senin";
    break;
  case 2:
    namaHari = "Selasa";
    break;
  case 3:
    namaHari = "Rabu";
    break;
  default:
    namaHari = "Tidak dikenal";
}
console.log(namaHari);

break menghentikan switch. Tanpanya, program akan terus "jatuh" ke case berikutnya.

4. Operator Ternary

const umur = 17;
const status = umur >= 17 ? "Boleh membuat KTP" : "Belum boleh";
console.log(status);

Bentuknya kondisi ? nilaiJikaBenar : nilaiJikaSalah. Gunakan untuk keputusan sederhana; untuk logika panjang, if lebih mudah dibaca.

Kesalahan Umum

  • Memakai = di dalam kondisi: if (x = 5).
  • Lupa break pada switch.
  • Menyusun urutan else if yang salah sehingga kondisi yang lebih luas menutupi yang sempit.

Latihan

Buat program yang menerima angka bulan (1 sampai 12) dan mencetak nama musimnya dengan switch. Lalu buat pengecek bilangan genap atau ganjil dengan ternary.

Rangkuman

if/else memilih satu jalur eksekusi, switch membandingkan satu nilai dengan banyak case, dan ternary meringkas keputusan sederhana. Ingat enam nilai falsy.
